# Атлас СУЛА — เว็บประกอบการเรียน

เว็บรวมเนื้อหาวิชาในหลักสูตร «Системы управления ракет-носителей и космических
аппаратов» (ВКА им. А. Ф. Можайского) สำหรับนักเรียนนายเรืออากาศไทยรุ่นต่อ ๆ ไป

ตอนนี้มีเนื้อหาเต็มเก้าวิชา: ТАУ · Системы навигации ЛА · ТОЭ · СУ РН · СУ КА ·
Техническая электроника · АСУ КА · НАС · ППО ЛА — รวม 162 หัวข้อ 235 แบบจำลอง
โต้ตอบ และรูปจากสไลด์ของภาควิชา 385 ภาพ

## โครงไฟล์

| ส่วน | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บ (โครงเปล่า อ้างถึง `app.css` กับ `app.js`) |
| `app.css` | รูปแบบทั้งหมด รวมของแต่ละวิชา |
| `app.js` | ตัวโปรแกรม — สารบัญ ค้นหา คลังศัพท์ แบบทดสอบ บัตรคำ และแบบจำลองทุกตัว |
| `data/t/<วิชา>__<หัวข้อ>.json` | เนื้อหาของแต่ละหัวข้อ โหลดเมื่อเลื่อนไปถึง |
| `data/ix/<วิชา>.json` | ข้อความสำหรับค้นหา โหลดเบื้องหลังหลังเปิดหน้า |
| `data/manifest.json` | รายชื่อวิชาที่มีเนื้อหาเต็ม |
| `figs/<รหัสรูป>.webp` | รูปแยกไฟล์ เบราว์เซอร์แคชเอง |
| `src/build_data.py` | สร้างดัชนีค้นหาใหม่หลังแก้เนื้อหา |

ไม่มีไฟล์ไหนใหญ่เกิน 200 KB นอกจาก `app.js` จึงไม่มีเพดานขนาดเหมือนตอนที่อยู่
ในรูป artifact — เพิ่มวิชาได้จนจบหลักสูตร

## แก้เนื้อหา

ต้นฉบับคือไฟล์ใน `data/t/` เอง — หนึ่งหัวข้อหนึ่งไฟล์ แก้ได้ตรง ๆ แล้วรัน

```bash
python3 src/build_data.py      # อัปเดตดัชนีค้นหาให้เห็นข้อความใหม่
```

เพิ่มวิชาใหม่: วางไฟล์หัวข้อลง `data/t/<วิชา>__<รหัสหัวข้อ>.json` วางรูปลง
`figs/` เพิ่มรูปแบบและแบบจำลองของวิชานั้นใน `app.css` กับ `app.js` แล้วรัน
สคริปต์ข้างบน

## ดูในเครื่องก่อนอัปขึ้นเว็บ

**ดับเบิลคลิก `preview.bat`** — จะเปิดเซิร์ฟเวอร์เล็ก ๆ แล้วเปิดเบราว์เซอร์ให้เอง
ปิดหน้าต่างสีดำเมื่อดูเสร็จ (ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ PowerShell ที่มากับวินโดวส์)

การดับเบิลคลิก `index.html` ตรง ๆ **จะไม่ขึ้นเนื้อหา** เพราะเบราว์เซอร์ห้ามหน้าเว็บ
ที่เปิดจากไฟล์ในเครื่องไปอ่านไฟล์ข้าง ๆ ซึ่งเว็บนี้ต้องทำ — ไม่ใช่ไฟล์เสีย

บนเครื่องที่มี Python ใช้ `python -m http.server 8000` แทนก็ได้

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository แบบ **public** บน GitHub
2. `git push` โค้ดทั้งหมดขึ้นไป
3. ในหน้า repository → Settings → Pages → Source เลือก **Deploy from a branch**
   แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
4. รอสักครู่ เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไฟล์ `.nojekyll` มีไว้ให้ GitHub ส่งไฟล์ทุกไฟล์ตามที่เป็น ห้ามลบ

ข้อจำกัดของ GitHub Pages แบบฟรี: เว็บละไม่เกิน 1 GB และแบนด์วิดท์ 100 GB ต่อเดือน
ตอนนี้เว็บนี้ใช้ประมาณ 27 MB

## ที่มาของเนื้อหา

เรียบเรียงจากสไลด์และตำราของภาควิชาที่สอนแต่ละวิชา แต่ละหัวข้อมีบรรทัดอ้างอิง
ต้นทางกำกับไว้ท้ายหัวข้อ ส่วนที่ผู้เรียบเรียงเพิ่มเข้ามาเอง (คำอธิบายภาษาไทย
แบบจำลอง และเฉลยที่คำนวณเอง) มีป้าย «ผู้เรียบเรียง» กำกับแยกจากเนื้อหาต้นฉบับ
