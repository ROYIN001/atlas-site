## ผู้อ่านทำอะไรได้บ้าง

- เมนูหลัก 5 พื้นที่ — หน้าหลัก · รายวิชา · ฝึกทบทวน · ค้นหา · ความก้าวหน้า (บนมือถืออยู่ที่แถบล่าง) · เมนูซ้ายย่อเหลือแถบไอคอนได้ · โหมดอ่านซ่อนเมนูทั้งหมด
- ทุกหน้า ทุกหัวข้อ และทุกจุดในหัวข้อมีที่อยู่ของตัวเอง (`#/<วิชา>/<หัวข้อ>/<id>`) — ส่งลิงก์ให้เพื่อน กด Back หรือรีเฟรชแล้วกลับมาตรงที่เดิม · ปุ่ม «เรียนต่อ» พากลับไปจุดที่อ่านค้าง
- สรุปทบทวนกับฉบับเต็มของทุกวิชา · ลิงก์ไปบรรยายที่อ้างถึงในบล็อกสรุปทำให้เอง · หัวข้อที่เกี่ยวข้อง (ทั้งในวิชาและข้ามวิชา) ท้ายหัวข้อ
- ค้นหาทุกวิชาทั้งไทยและรัสเซีย (ё = е · ชื่อพ้องเช่น Kalman/Калман) แล้วเปิดหัวข้อพร้อมไฮไลต์คำที่ค้น
- ฝึกทบทวน: ซ้อมสอบปากเปล่าแบบปิดคำตอบแล้วให้คะแนนตัวเอง · ฟังคำตอบภาษารัสเซียด้วยเสียงในเครื่อง · ควิซในหัวข้อ · Flashcard · ควิซศัพท์
- ทวนตามกำหนด (spaced repetition) · ตั้งวันสอบแล้วได้แผนรายวัน · โหมดคืนก่อนสอบ (สรุป กับดัก และคำถามปากเปล่าทั้งวิชาในหน้าเดียว)
- ปักหัวข้อ · ประวัติการอ่าน · บันทึกส่วนตัวท้ายหัวข้อ · คัดลอกลิงก์ · แจ้งจุดผิด
- เก็บวิชาไว้อ่านออฟไลน์และติดตั้งเป็นแอปบนมือถือ · ดู/อัปเดต/ลบสำเนาในหน้าความก้าวหน้า
- ความคืบหน้าทั้งหมดเก็บในเบราว์เซอร์ของผู้อ่านเอง ไม่ส่งไปที่ใด · สำรองและนำเข้าเป็นไฟล์ได้ (นำเข้าแล้วกู้คืนชุดเดิมได้) · หน้าเว็บไม่เรียกเซิร์ฟเวอร์ภายนอกเลย

## โครงไฟล์

| ส่วน | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บ (โครงเปล่า อ้างถึง `app.css` กับ `app.js`) |
| `app.css` | รูปแบบทั้งหมด รวมของแต่ละวิชา |
| `app.js` | ตัวโปรแกรม — สารบัญ ค้นหา คลังศัพท์ ฝึกทบทวน ทวนตามกำหนด และแบบจำลองทุกตัว |
| `data/t/<วิชา>__<หัวข้อ>.json` | เนื้อหาของแต่ละหัวข้อ (288 ไฟล์) โหลดเมื่อเลื่อนไปถึง — **ต้นฉบับเนื้อหาอยู่ที่นี่** |
| `data/ix/<วิชา>.json` | ข้อความสำหรับค้นหา โหลดทีละวิชาเมื่อเริ่มค้นหา (สร้างอัตโนมัติ) |
| `data/manifest.json` | รายชื่อวิชาที่มีเนื้อหาเต็มพร้อมเลขรุ่นของแต่ละวิชา (สร้างอัตโนมัติ) |
| `data/qa/` · `data/rel.json` · `data/figdim.json` | คำถามปากเปล่า · หัวข้อที่เกี่ยวข้อง · ขนาดรูป (สร้างอัตโนมัติจาก `data/t` และ `figs/`) |
| `data/vh/` · `data/ih/` | แผนที่และควิซของวิชาประวัติศาสตร์ (ВИ · История) |
| `figs/<รหัสรูป>.webp` | รูปแยกไฟล์ เบราว์เซอร์แคชเอง |
| `fonts/` | ฟอนต์ของเว็บ (IBM Plex, Noto Sans Math) เก็บไว้เองไม่ต้องพึ่ง Google — สร้างใหม่ด้วย `python src/fetch_fonts.py` |
| `sw.js` · `manifest.webmanifest` · `icons/` | อ่านแบบออฟไลน์และติดตั้งเป็นแอปบนมือถือ (ทำงานเฉพาะบนเว็บจริง ไม่ทำงานตอนดูในเครื่อง) |
| `js/subj/<วิชา>.js` | (ยังไม่มี) แบบจำลองของวิชาที่ยกระดับต่อจากนี้ โหลดเมื่อเปิดวิชานั้น (ดู CLAUDE.md หัวข้อ 13) |
| `src/build_data.py` | สร้างดัชนีค้นหา เลขรุ่นแคช และไฟล์อัตโนมัติทั้งหมดใหม่หลังแก้เนื้อหา (ขั้นเพิ่มเติมอยู่ใน `src/build_steps/`) |
| `src/verify.py` · `tests/` · `.github/workflows/` | ตรวจทั้งเว็บในเบราว์เซอร์ · เทสต์อัตโนมัติ · ตรวจซ้ำบน GitHub ทุก pull request |

ไฟล์ใหญ่สุดคือ `app.js` (6.3 MB) กับดัชนีค้นหาของบางวิชา (สูงสุด 5.6 MB ซึ่งโหลดเมื่อเริ่มค้นหาเท่านั้น)
— ไม่มีเพดานขนาดเหมือนตอนที่อยู่ในรูป artifact เพิ่มวิชาได้จนจบหลักสูตร

## แก้เนื้อหา

ต้นฉบับคือไฟล์ใน `data/t/` เอง — หนึ่งหัวข้อหนึ่งไฟล์ แก้ได้ตรง ๆ แล้วรัน

```bash
python3 src/build_data.py      # อัปเดตดัชนีค้นหา เลขรุ่นแคช และไฟล์อัตโนมัติให้เห็นข้อความใหม่
node --test tests/*.test.cjs   # เทสต์อัตโนมัติ (ต้องผ่านก่อน commit)
```

เพิ่มวิชาใหม่หรือยกระดับวิชา: ทำตามเช็กลิสต์ใน CLAUDE.md หัวข้อ 3, 13 และ 14 — วางไฟล์หัวข้อลง
`data/t/<วิชา>__<รหัสหัวข้อ>.json` วางรูปลง `figs/` ใส่แบบจำลองของวิชาใน `js/subj/<วิชา>.js`
แล้วรันสองคำสั่งข้างบน (วิชาใหม่หรือเพิ่ม/ลดเนื้อหาโดยตั้งใจ: `python src/counts.py --update` ก่อน `node --test`) ตามด้วย `python src/verify.py --subject <วิชา> --mobile`

## ดูในเครื่องก่อนอัปขึ้นเว็บ

**ดับเบิลคลิก `preview.bat`** — จะเปิดเซิร์ฟเวอร์เล็ก ๆ แล้วเปิดเบราว์เซอร์ให้เอง
ปิดหน้าต่างสีดำเมื่อดูเสร็จ (ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ PowerShell ที่มากับวินโดวส์)

การดับเบิลคลิก `index.html` ตรง ๆ **จะไม่ขึ้นเนื้อหา** เพราะเบราว์เซอร์ห้ามหน้าเว็บ
ที่เปิดจากไฟล์ในเครื่องไปอ่านไฟล์ข้าง ๆ ซึ่งเว็บนี้ต้องทำ — ไม่ใช่ไฟล์เสีย

บนเครื่องที่มี Python ใช้ `python -m http.server 8000` แทนก็ได้

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository แบบ **public** บน GitHub
2. `git push` โค้ดทั้งหมดขึ้นไป
3. ในหน้า repository → Settings → Pages → Source เลือก **Deploy from a branch**
   แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
4. รอสักครู่ เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไฟล์ `.nojekyll` มีไว้ให้ GitHub ส่งไฟล์ทุกไฟล์ตามที่เป็น ห้ามลบ

ข้อจำกัดของ GitHub Pages แบบฟรี: เว็บละไม่เกิน 1 GB และแบนด์วิดท์ 100 GB ต่อเดือน
ตอนนี้ทั้ง repo ใช้ประมาณ 100 MB
