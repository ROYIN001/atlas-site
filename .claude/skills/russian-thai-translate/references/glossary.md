# RU–TH Glossary

A running list of terms with a confirmed translation, so the skill stays consistent across sessions instead of re-deriving the same term differently each time.

**How to use this file:** check here before translating a technical/institutional term. If a term isn't listed and you had to make a judgment call, translate it inline and flag it as uncertain in the output notes (see SKILL.md step 4) — then add it here once the user confirms the correct version, so it doesn't need to be re-flagged next time.

Entries marked "⚠ needs verification" are reasonable working translations, not confirmed institutional/standard terms — treat them as a starting guess, not ground truth.
