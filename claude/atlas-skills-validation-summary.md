## งานจำลองและข้อจำกัด

ใช้ตัวอย่างสังเคราะห์ระบบอันดับหนึ่ง G(p)=K/(Tp+1), T>0, สภาวะเริ่มต้นศูนย์ และสัญญาณขั้นบันไดหนึ่งหน่วย ตัวอย่างจงใจใส่สูตรและคำตอบตัวเลขผิด นิยามค่าคงตัวเวลาคลาดเคลื่อน คำอ้างข้อสอบทางการที่ไม่มีหลักฐาน ผู้แก้ต้นฉบับซ้ำกัน และผล PASS ก่อนแก้ไฟล์

เกณฑ์ห้าข้อคือ แก้สูตรและค่า y(4) รักษารหัสคำถามเดิม ปฏิเสธคำอ้างข้อสอบที่ไม่มีหลักฐาน แยกเจ้าของไฟล์และงานประกอบ และไม่ใช้ผลตรวจเก่ารับรองงานใหม่ งานที่ใช้สกิลแบบครบชุดสร้าง manifest และรันตัวตรวจจริงจนผ่านในสถานะ blocked เพราะขาดเครื่องมือประกอบและต้นฉบับจริง

ผลทดลองมาจากสองสถานการณ์ สถานการณ์ละหนึ่งครั้งต่อรูปแบบ ทั้งแบบใช้และไม่ใช้สกิลผ่าน 10/10 เกณฑ์ จึงยังสรุปไม่ได้ว่าสกิลเพิ่มคุณภาพหรือประหยัดเวลาเหนือ baseline อย่างมีนัยสำคัญ จุดที่ตรวจเห็นคือการใช้สัญญาส่งต่องานร่วมกันและระบุสิ่งที่ยังไม่พร้อมได้ตรงไปตรงมา ไม่ได้วัดเวลา จำนวน token หรือความเสถียรจากการทำซ้ำ

หน้า HTML ผลทดลองชุดเดิมถูกนำออกจาก repository แล้ว เพราะ GitHub Pages เผยแพร่หน้าที่เรียกเซิร์ฟเวอร์ภายนอกบน origin เดียวกับเว็บผู้เรียน และผลประเมินชุดนั้นแยกแยะไม่ได้ ผลประเมินชุดใหม่จะอยู่ใน `atlas-skills-evaluation.md`

ไม่มีการแก้บทเรียนหรือรัน build/browser tests ของเว็บไซต์ในการสร้างสกิลครั้งนี้ ผลข้างต้นไม่รับรองเนื้อหาจริง การเผยแพร่เว็บ หรือความสมบูรณ์ของเครื่องมือ STD2 บนเครื่องผู้ใช้ ตัวตรวจ manifest ไม่พิสูจน์ตัวตนผู้ตรวจ ไม่ล็อกโปรเซส และไม่รับรองความถูกต้องทางวิชาการแทนผู้ตรวจ
