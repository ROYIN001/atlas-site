## 0.1 ⚠️ ห้ามทำเนื้อหาวิชาอื่นหาย

**แก้เฉพาะสิ่งที่ถูกสั่งเท่านั้น — ส่วนอื่นทั้งไฟล์ต้องเหมือนเดิมทุกไบต์**

มีหลายเซสชันทำงานบน artifact ตัวเดียวกันพร้อมกัน แต่ละเซสชันอาจกำลังเขียนวิชาคนละวิชาอยู่
ถ้าเซสชันหนึ่งเขียนไฟล์ใหม่ทั้งก้อน งานของอีกเซสชันจะหายทันที **เคยเกิดขึ้นมาแล้ว 2 ครั้ง**

ข้อห้ามเด็ดขาด:

- ❌ ห้ามเขียนไฟล์ใหม่ทั้งก้อนแล้วเผยแพร่ทับ
- ❌ ห้ามลบ/ย่อ/ตัดทอน `DEEP.<id>` ของวิชาที่ไม่ได้ถูกสั่งให้แก้
- ❌ ห้ามลบรายการใน `SUBJECTS`, `MODULES`, `DEMOS`, ค่าคงที่ `SVG_*` ที่ไม่เกี่ยวกับงานที่สั่ง
- ❌ ห้าม "จัดระเบียบ" หรือ "ทำความสะอาด" โค้ดส่วนที่ไม่ได้สั่ง
- ❌ ห้ามสร้างไฟล์จากความจำ หรือจากไฟล์เก่าที่ค้างอยู่ในเครื่อง

วิธีที่ถูก — **ต่อเติมอย่างเดียว (additive-only)** ด้วย patch เฉพาะจุด:

```python
s = open('study-program.html').read()
assert s.count(old) == 1          # ต้องเจอที่เดียวเป๊ะ ๆ
s = s.replace(old, new)           # แก้เฉพาะจุดนั้น
```

**เวลาต้อง «ทำใหม่» วิชาเดิม:** เขียน `strip.py` ที่ถอดเฉพาะบล็อกของวิชานั้นออกจากไฟล์ล่าสุด (CSS ของวิชา, `DEEP.<id>`, ฟังก์ชัน demo, key ใน `DEMOS`, ก้อนรูป) แล้ว `assert` ว่าไม่มีเศษของวิชานั้นเหลือ และบล็อกของวิชาอื่นยังอยู่ครบ → ค่อยประกอบของใหม่เข้าไปแทน (ใช้กับ СУ КА 30 ส.ค. ได้ผล)

## 1. โครงไฟล์

ไฟล์ HTML เดี่ยวจบในตัว ไม่มี dependency ภายนอกนอกจาก Google Fonts (IBM Plex Sans / Mono / Sans Thai)

| ส่วน | เนื้อหา |
|---|---|
| `<style>` | CSS ทั้งหมด ใช้ custom properties (`--bg`, `--ink`, `--accent`, `--accent-2`, `--wash`, `--ok`, `--crit`, `--bk-*` สีหมวด …) · บล็อก v2/v2.1 อยู่ท้าย `<style>` คั่นด้วยคอมเมนต์ `v2:` / `v2.1:` |
| `<script>` #1 | **DATA** — `MODULES`, `PROGRAM`, `BLOCKS`, `YEARS`, `SUBJECTS`, `DEEP`, ค่าคงที่ `SVG_*` |
| `<script>` #2 | **DEMOS** — `Plot`, `buildDemo`, ฟังก์ชัน `demoXxx` ทุกตัว, ตาราง `DEMOS` |
| `<script>` #3 | **APP** — nav (`buildNav()`/`mkFold`), router `go()` (routes รวม `flash`), `renderSubject()` (crumb/fold/toc/SPY_IO), `renderFlash()`, ค้นหา, ควิซ, ตัวปรับภาคเรียน, `ICONS`, wiring `#bbar`/`#topBtn` |

**จุดที่ปลอดภัยสำหรับต่อเติมวิชาใหม่** — เพิ่มบล็อกใหม่แยกก้อน ไม่ไปยุ่งของเดิม:

```js
/* ================= <ชื่อวิชา> ================= */
const SVG_XXX = '…';          // ภาพเฉพาะวิชานี้
DEEP.xxx = { … };             // เนื้อหาเต็ม
```
แล้วเติม `demoXxx` ต่อท้ายบล็อก DEMOS และลงทะเบียนแบบไม่แตะบรรทัดเดิม: ให้ไฟล์ demo เขียนลง `window.XXDEMOS` แล้วต่อท้ายบรรทัด `const DEMOS = {…};` ด้วย `Object.assign(DEMOS, window.XXDEMOS || {});` · รูปใช้ key ไม่ชน (`te-f01`…) แล้ว `Object.assign(SUKAFIGS, XXFIGS)` — `window.SUKAFIG(view)` ถูกเรียกทุกหน้าวิชาอยู่แล้ว · `SUBJECTS` แก้แค่ฟิลด์ `deep: true` ของวิชานั้น · ไอคอนเติม key ต่อท้าย `const ICONS = {…}` ในบล็อก APP (เช่น `asu: "📡"`)

**CSS ของแต่ละวิชาต้อง namespace** — ครอบ html ของทุกหัวข้อด้วย `<div class="ชื่อวิชา">` แล้วเขียน CSS เป็น `.suka <selector>` / `.surn <selector>` · ระวัง CSS ฐานของ atlas ที่รั่วเข้ามา (`.eq{white-space:pre}` และ `.readout{display:flex}`) ต้อง override กลับเป็น `normal` / `block` ภายใน namespace · **CSS ที่ต้องเพิ่มทุกครั้งที่ตั้ง namespace ใหม่:**

```css
.xx .demo-head { flex-wrap: wrap; }               /* แบบจำลองที่มีปุ่มเยอะจะล้นบนมือถือ */
.xx .demo-head button { … }  .xx .demo-head button.on { … }   /* atlas ไม่มีสไตล์ปุ่ม demo เป็นค่าเริ่มต้น */
.xx .demo .readout > span { margin-right: 20px; } /* readout ถูก override เป็น block จึงเสียช่องไฟของ flex */
.xx .demo .ctl label { display: block; }          /* ป้ายที่มี <sub> จะโดน space-between ฉีกออกจากกัน */
.xx .demo .ctl label b { float: right; }
.xx .cols2 > .card { min-width: 0; }              /* การ์ดที่มีตารางข้างในทำหน้าล้นแนวนอน */
.xx .card .tw { max-width: 100%; overflow-x: auto; }
```
**อย่าลืมตัดกฎ `#figlb` ออก** เวลาคัดลอกบล็อก CSS ของวิชาก่อนหน้า — เป็น id ระดับหน้า มีอยู่แล้ว · CSS ของวิชาใหม่ต้องไม่ทับส่วนมือถือ v2 (`#bbar`, `#topBtn`, `main.stage` padding-bottom 140 px)

**ธีม:** ต้องรองรับทั้ง light/dark เสมอ — นิยามสีที่ `:root`, แล้ว override ใน `@media (prefers-color-scheme: dark) :root:not([data-theme="light"])` และ `:root[data-theme="dark"]` · มี `MutationObserver` บน `data-theme` ที่สั่ง `LIVE.forEach(d => d.draw())` — เดโมทุกตัวจึงต้องอ่านสีผ่าน `CV()` ในฟังก์ชัน `draw` เท่านั้น (ห้าม cache สีไว้นอก draw)

**localStorage (ห้ามใช้ชื่อชนกัน):** `atlas-sula-v1` (ความคืบหน้า) · `atlas-mode-v1` (โหมดสรุป/เต็ม) · `atlas-sem-v1` (ภาคเรียนที่ผู้ใช้แก้เอง) · `atlas-bm-v1` (บุ๊กมาร์กศัพท์) · `atlas-last-v1` ({v,id,y} ตำแหน่งอ่านล่าสุด) · `atlas-rail-v1` (ภาคเรียนที่กางอยู่ในแถบซ้าย)

## 2. โครงข้อมูลรายวิชา

```js
{ n: 39, id: "nav", block: "СД", sems: [6], ze: 5, deep: true,
  ru: "Системы навигации летательных аппаратов",
  th: "ระบบนำร่องอากาศยานและยานอวกาศ",
  desc: "คำอธิบายสั้นหนึ่งบรรทัด",
  topics: ["หัวข้อ 1", "หัวข้อ 2"] }   // ใช้เฉพาะวิชาที่ยังเป็นโครงร่าง
```

- `n` = เลขอ้างอิงคงที่ **ห้ามเปลี่ยน** (ใช้อ้างอิงเวลาสั่งงาน)
- `block` ∈ ГСЭ / МЕН / ОПД / СД / ВПД
- `sems` = **ทุกภาคที่เรียนจริง** เช่น `[1,2,3,4,5,6,7,8,9]` สำหรับภาษาต่างประเทศ
- `deep: true` = มีเนื้อหาเต็มใน `DEEP[id]`
- ตั้งแต่ 01.09.2026: `PROGRAM.onBreak = false` (เทอม 9 เริ่มแล้ว — พลิกกลับเป็น true เมื่อปิดเทอม)

## 3. โครงเนื้อหาเต็ม `DEEP.<id>` — แม่แบบ (ปรับได้ตามวิชา)

```js
DEEP.xxx = {
  ru, th,
  lede: "ย่อหน้าเปิดว่าวิชานี้คืออะไร ทำไมสำคัญ เชื่อมกับวิชาอื่นอย่างไร",
  summary: [ ... ],   // โหมด «สรุปทบทวน» — หน้าเดียวจบก่อนสอบ
  topics:  [ ... ]    // โหมด «ฉบับเต็ม» — เรียนจริงทีละหัวข้อ
};
```

### 3.1 `summary[]` — 4 บล็อกมาตรฐาน

| id | ru / th | เนื้อหา |
|---|---|---|
| `xxx-s1` | Определения к экзамену / นิยามที่ต้องตอบได้ | `<div class="defgrid">` + `<div class="def">` |
| `xxx-s2` | Формулы / สูตรที่ต้องจำ | `<div class="ftable"><table>` + `<div class="eq">` |
| `xxx-s3` | Схемы / แผนภาพที่ต้องวาดเป็น | `<figure class="dia">${SVG_XXX}<figcaption>…` |
| `xxx-s4` | Частые вопросы / คำถามที่ออกสอบบ่อย | `<details class="qa"><summary>…<span class="extag">แท็ก</span>` |

วิชาที่เนื้อหาไม่เข้าโครงนี้ ปรับ/ตัด/เพิ่มบล็อกได้ตามจริง

โครงการ์ดนิยาม:
```html
<div class="def">
  <b>Термин</b><i>คำแปลไทย</i>
  <em>ประโยคภาษารัสเซียที่ตอบในห้องสอบได้ทันที</em>   <!-- ขึ้นหัวว่า «Ответ на экзамене» อัตโนมัติ -->
  <span>คำอธิบายไทยแบบขยายความ</span>
</div>
```

### 3.2 `topics[]` — ฉบับเต็ม

- หนึ่งหัวข้อ = หนึ่งบรรยาย (`id: "xxx-1"`, `"xxx-2"`, …) · หัวข้อแรกเป็น `xxx-map` (แผนที่หลักสูตร: หัวข้อ ↔ เลขบรรยาย ↔ ตำรา ↔ คำถามสอบ)
- เปิดด้วย `<p><b>Цель лекции:</b> …</p>`
- ซอยด้วย `<div class="sechead"><h3>หัวข้อย่อย</h3><span>หมายเหตุขวา</span></div>`
- สูตรอยู่ใน `<div class="eq">…<span class="cap">คำอธิบายใต้สูตร</span></div>`
- ข้อสังเกต/กับดักข้อสอบอยู่ใน `<div class="callout">`
- **ปิดท้ายทุกหัวข้อด้วย** `${SRC("Лекция N (текст + M слайдов)", "ตำรา — §x.y «ชื่อหัวข้อ» с. aa–bb")}`
- หัวข้อสุดท้ายชื่อ `xxx-ex` — **Задачи с решениями / แบบฝึกหัดพร้อมเฉลย** ใช้ `<details class="ex">` ทำเฉลยทีละขั้น พร้อมตัวเลขจริง
- ห้ามใช้ backtick และ `${` ในเนื้อหา (ยกเว้นบรรทัด SRC) · ทุกหัวข้อและทุกเดโมต้องผ่าน `node --check` ในรูป `const X = <เนื้อหา>;` ก่อนประกอบ

- **ต้นฉบับเป็นหลัก** — สูตร ตัวเลข สัญลักษณ์ เลขสมการ ต้องตรงกับสไลด์/ตำราจริง และอ้างเลขหน้าไว้ · จุดที่สไลด์ผิดจริง (พิสูจน์ได้จากสมการข้างเคียงของสไลด์เอง): แก้ได้ แต่ต้องใส่ **«หมายเหตุต้นฉบับ»** บอกว่าสไลด์พิมพ์อะไร (ณ 01.09 มี 17 จุด + АСУ КА อีกหลายจุด — ห้ามลบ) · จุดผิดของต้นฉบับทุกวิชารวบรวมไว้ในสารสกัด `дисциплины/_черновики/*-конспект-источников.md`
- **สัญกรณ์ ВКА:** ตัวแปรลาปลาส **p** (ไม่ใช่ s), **a₀ = สัมประสิทธิ์กำลังสูงสุด**, Михайлов ไม่อยู่ในตำรา Лучко · มุมท่าทางใช้ **Pitch / Yaw / Roll** (วงเล็บ тангаж/рыскание/вращение ได้) — คำสั่งเจ้าของ 31 ส.ค.
- **สองภาษา** — หัวข้อและศัพท์เทคนิคเป็นรัสเซีย คำอธิบายเป็นไทย (ค้นหาศัพท์รัสเซียได้ง่ายกว่า) · **ห้ามให้อักษรไทยติดกับซีริลลิกโดยไม่มีช่องว่าง** (regex `[฀-๿][А-я]|[А-я][฀-๿]` ต้องได้ 0)
- **ห้ามทับศัพท์รัสเซียเป็นไทยถ้ามีคำไทยอยู่แล้ว** — «หัวข้อ» ไม่ใช่ «เทมา», «ภาควิชา» ไม่ใช่ «คาเฟดรา», «ชุดข้อสอบ» ไม่ใช่ «บิลเล็ต», «ภาพระนาบเฟส», «บรรยายที่ N», «โทรมาตร» (ไม่ใช่ «เทเลเมทรี»), «ท่อน» (ไม่ใช่ «สเตจ»), «ฐานปล่อย» (ไม่ใช่ «คอสโมโดรม»), «ไจโร» (ไม่ใช่ «กิโร»), «ไบแอส», «เชิงอรรถ» (ไม่ใช่ «สโนสกา»), «ตัวทวนสัญญาณ» (ไม่ใช่ «รีพีตเตอร์»), «ชุดควบคุมบนยาน (БКУ)», «จุดควบคุม» (ไม่ใช่ «พุนต์») · ถ้าไม่มีคำไทยที่ตรง **คงคำรัสเซียเป็นซีริลลิก**: датчик, спарка, дроссель (บริบทอิเล็กทรอนิกส์), оптрон/тринистор/симистор, вариант, циклограмма
- **มติศัพท์ 16 ข้อของเจ้าของ (02.09 — มีผลทั้งฉบับ ห้ามใช้คำเก่า):** «คาสเคด» → **ภาค / ภาคขยาย** (การต่ออนุกรม → «ต่อเรียง»; «คาสโคด» = cascode คงทับศัพท์) · дроссель ในบริบทของไหล/СУРТ/РКС → **ตัวหรี่การไหล** · **สัญญาณโหมดร่วม** · **กรอบแกนหมุน** (карданов подвес) · **ย่านไม่ตอบสนอง** · **การหมุนควง (พรีเซสชัน)** · **การปรับวงโคจร** (ไม่ใช่ «การแมนูเวอร์») · **การหมุนรอบแกนออยเลอร์ครั้งเดียว** (ไม่ใช่ «เอ็กซ์เทนซีฟ») · скважность → **ดิวตี้ไซเคิล (สัดส่วนเวลาติดต่อคาบ)** · ซีเนอร์ไดโอด + (стабилитрон) · อัตราส่วนแรงยกต่อแรงต้าน + (качество K) — ตารางมติเต็มอยู่ใน skill `russian-thai-translate`
- เน้น «ที่มาของสูตร» และ «ทำไม» ไม่ใช่ท่องผลลัพธ์ · ชี้กับดักที่เสียคะแนนบ่อย และเชื่อมโยงข้ามบรรยาย/ข้ามวิชา
- ความรู้เสริมที่ไม่อยู่ในสไลด์ (การขยายตัวย่อที่สไลด์ไม่ให้, ตัวเลขจากแหล่งอื่น, สูตรเรขาคณิตวงโคจร) **ต้องติดป้าย «ผู้เรียบเรียง/ผู้เรียบเรียงเสริม»** — ผู้ตรวจอิสระของ АСУ КА พบจุดไม่ติดป้าย ~60 จุด ต้องกวาดทุกครั้ง

## 4. แบบจำลองโต้ตอบ (демонстрации) — **สิ่งที่เจ้าของโปรเจกต์ต้องการมากที่สุด**

> «สิ่งที่อยากได้มากที่สุดที่อาจารย์ไม่มีคืออนิเมชันแบบจำลองต่าง ๆ ใส่ในทุกหัวข้อที่เป็นไปได้ยิ่งดี» — คำสั่ง 30 ส.ค. 2026

**เป้าหมาย: ทุกหัวข้อที่ใส่แบบจำลองได้ ต้องมีแบบจำลองของตัวเอง** ยกเว้นได้เฉพาะหัวข้อที่เป็นรายการอ้างอิงล้วน (ตัวย่อ / ศัพท์ / ตำรา / แผนที่หลักสูตร) · ตัวอย่างมาตรฐาน: СУ КА 18 ตัว, АСУ КА 15 ตัว — **วิชาเชิงพรรณนาก็ทำเดโมได้** (สูตรจากงานปฏิบัติ + เรขาคณิตวงโคจรของผู้เรียบเรียง + แอนิเมชันเชิงโครงสร้าง เช่น วงจร 6 ขั้น СКПО, циклограмма ТЦУ, ตัววางแผน ОКИК) · รายชื่อเดโมทุกตัวดูได้จากตาราง `DEMOS` ใน artifact
**เดโมที่ลงทะเบียนใน `DEMOS` ต้องถูกวางในเนื้อหาเสมอ** (เคยมี `euler`, `geo` ตายอยู่ 2 วัน — `assemble.py` ต้อง assert ข้อนี้)

```js
function demoXxx(host) {
  buildDemo(host, {
    label: "Лекция N · หัวข้อ",
    title: "อธิบายว่าเลื่อนแล้วจะเห็นอะไร",
    ratio: 0.56, animate: false,
    legend: '<span><i style="background:var(--accent)"></i>…</span>',
    controls: [{ id, label, min, max, step, value, fmt }],
    buttons:  [{ id, label, toggle: true, value: true }],
    draw(ctx, w, h, s, readout, t) { /* คำนวณสดจากสมการจริง */ }
  });
}
```
- วางในเนื้อหาได้ 2 แบบ: `demo: "key"` / `demos: ["k1","k2"]` ที่ระดับหัวข้อ **หรือ** ฝัง `<div data-demo="key"></div>` ลงกลาง html ตรงจุดที่อธิบายเรื่องนั้นพอดี (แบบหลังดีกว่า) — `renderSubject` สแกนทั้ง `view` จึงติดตั้งให้เอง
- ใช้คลาส `Plot` สำหรับกราฟ (`frame`, `line`, `band`, `dots`, `clip`) · อ่านสีจาก `CV("--accent")` ภายใน `draw()` เสมอ ห้าม hard-code (ยกเว้นสีเน้นพิเศษ เช่น `#4F7FD0`)
- `readout` ต้องสรุปผลเป็นตัวเลขพร้อมคำตัดสิน `class="good"` / `class="bad"` · `buildDemo` ใส่ `role="img"` + `aria-label` ให้ canvas อัตโนมัติ
- **ต้องคำนวณจากสมการจริงของภาควิชา** ไม่ใช่วาดรูปหลอก แล้วตรวจตัวเลขกับตำรา (Гоман LEO→ГСО = 2,399 + 1,457 = 3,857 km/s; Θ_вх ของการลงจากวงโคจร −1°…−3°; W_max ของ ПЗ 5 = 96/200/96/84/106/171)
- **ตรวจทุกตัวด้วย Playwright** แล้ว **ดูภาพจริงทีละอัน** — bug เรื่องเครื่องหมาย/เรขาคณิตเห็นได้จากภาพเท่านั้น

## 4b. รูปภาพจากสไลด์ — **เอาเฉพาะตัวรูป ห้ามเอาสไลด์ทั้งแผ่น**

> «เอาแค่ตัวภาพที่อยู่ในสไลด์ ไม่ใช่เอามาทั้งสไลด์ สไลด์มีแยกอยู่แล้วไปเปิดหาเองได้ ที่ต้องการคือเอามาประกอบความเข้าใจในบางเรื่องที่มีความจำเป็น» — คำสั่ง 30 ส.ค. 2026

1. แตก media ที่ฝังอยู่ใน .pptx โดยตรง — `unzip -j "file.pptx" 'ppt/media/*' -d out/` → ได้ตัวรูปจริงไม่มีกรอบสไลด์/หัวเรื่อง/โลโก้
2. กรองด้วยขนาด (≥ 340×240) และ md5 (ตัดโลโก้/ตราสถาบันที่ซ้ำทุกไฟล์)
3. contact sheet 15–25 รูปต่อแผ่น → **ดูด้วยตาแล้วเลือกทีละรูป** ว่ารูปไหนช่วยเข้าใจจริง
4. `trim` ขอบด้วย `ImageChops.difference` เทียบสีมุมภาพ, พื้นเทาของสไลด์ → ขาว, ย่อกว้าง ≤ 900 px, WebP q72 → data URI (75 รูป ≈ 0,95 MB) · .wmf/.emf ผ่าน `soffice --convert-to png` ก่อน แล้ว **trim ก่อนทำ contact sheet** · PNG แบบ RGBA พื้นโปร่งเส้นเข้มต้อง alpha-composite ลงขาวก่อน ไม่งั้นได้สี่เหลี่ยมดำ
5. วาง **ทีละรูปตรงจุดที่อธิบายเรื่องนั้น** ด้วย `<figure class="ifig" data-fig="ID">` + คำบรรยายรัสเซีย + คำอธิบายไทยหนึ่งบรรทัด, lazy-load ด้วย IntersectionObserver + lightbox — ตัวโหลด **ซ่อน figure อัตโนมัติถ้า `SUKAFIGS[id]` ไม่มีไฟล์**
6. **ห้ามทำแกลเลอรีสไลด์ทั้งบรรยาย** — เจ้าของปฏิเสธวิธีนี้ไปแล้ว

**สูตรในสไลด์มักเป็นรูป MathType** (ТЭ, СУ РН) — ชั้นข้อความของ .pptx ไม่มีสูตร ต้อง `soffice --headless --convert-to pdf` แล้ว **อ่าน PDF ทีละ 6–8 หน้าด้วยตาและเขียนโน้ตลงไฟล์ทันที** (รูปหน้าถูกไล่ออกจากบริบทเมื่อโหลดหน้าใหม่)

## 8. สองเล่ม (v3 — 07.09.2026)

**ทำไมต้องแยก:** artifact มีเพดานขนาด **16 MB** · atlas 13,13 MB + ППО 4,12 MB = **17,25 MB** จึงเกิน · การบีบรูป WebP ซ้ำไม่ช่วย — q40 / กว้าง 600 px ลดก้อนรูป ППО ได้แค่ 1,73 → 1,37 MB และป้ายภาษารัสเซียในรูปอ่านไม่ออก จึงต้องแยกเล่ม

**กลไก** (โค้ดชุดเดียวกันในทั้งสองเล่ม):
- ค่าคงที่ `VOL` (เลขเล่มของไฟล์นี้) และ `VOLS = {1:{url,label,note,subj:[…]}, 2:{…}}` วาง**ต่อจาก `const ICONS`** ในบล็อก APP
- `go()` ดูว่าวิชาปลายทางอยู่เล่มไหน — ถ้าอยู่คนละเล่ม เปิดอีกเล่มใน**แท็บใหม่** ที่ `<url>#s=<id>`
- **ลิงก์ลึก `#s=<id>`** ต้องทำงานทั้ง**ตอนโหลดหน้า**และ**ตอน `hashchange`**
- การ์ดวิชาได้ป้าย «เนื้อหาเต็ม · เล่ม N» (`.pill.vol`) · ปุ่มของวิชาที่อยู่อีกเล่มในแถบซ้ายได้คลาส `.other` + แท็ก «เล่ม N» · สวิตช์สลับเล่ม `.volsw` อยู่ใต้ชื่อแอป
