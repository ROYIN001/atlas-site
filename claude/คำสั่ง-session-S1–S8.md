# คำสั่งสำหรับ 8 session คู่ขนาน — ยกระดับโครงเว็บรอบ 2 (27 ก.ย. 2026)

## วิธีใช้ (สำหรับ Royin)

1. **merge PR «เตรียมพื้น» เข้า `main` ก่อน** (hooks · ช่อง SLOT · build_steps) ไม่งั้นทุก session จะชนกันที่ `app.js`
2. เปิด session ใหม่ของ Claude Code บน repo `ROYIN001/atlas-site` (จาก `main` ล่าสุด) หนึ่ง session ต่อหนึ่งหัวข้อด้านล่าง — คัดลอกทั้งกล่องคำสั่งวางเป็นข้อความแรก
3. เปิดกี่ session พร้อมกันก็ได้ แต่ละ session แตะคนละไฟล์/คนละช่อง ถ้าเปิดทีละน้อย แนะนำ **S1 กับ S8 ก่อน** (เป็นด่านและความปลอดภัยของข้อมูลที่ session อื่นพึ่ง) แล้ว S2 → S3 → S4 → S5 → S6 → S7
4. ทุก session จะจบด้วยการเปิด Pull Request ให้เอง — **merge ตามลำดับ S1 → S8 → S2 → S3 → S4 → S5 → S6 → S7** ก่อน merge PR ถัดไป กดปุ่ม **Update branch** บนหน้า PR ถ้า GitHub บอกว่ามี conflict ให้ส่งข้อความในเซสชันนั้นว่า «รวม main แล้วแก้ conflict»
5. merge ครบแล้ว เปิด session สุดท้าย (S9 ท้ายไฟล์) ตรวจทั้งเว็บและปิดรุ่น
